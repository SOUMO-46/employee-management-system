# Employee Management System — Professional

PHP OOP + MySQL employee operations system with REST API.

## Modules
- Dashboard
- Employee CRUD + search + pagination
- Attendance with entry/exit validation
- Leave requests + approval/rejection + overlap protection
- Monthly payroll
- REST API
- CSRF-protected browser forms
- Responsive glass UI with motion/VFX

## Setup
1. Create/import `database/database.sql` in MySQL. It creates `employee_management` and inserts demo employees.
2. Set DB credentials in `config/config.php`.
3. Point Apache/Nginx document root to `public/`.
4. Open `public/index.php`.
